# バスケットボール ホワイトボード

コーチや選手がバスケットボールのプレー（オフェンス・ディフェンスの動き、パス、スクリーンなど）を
図解できるホワイトボードアプリです。

## 技術構成

- React + TypeScript
- 描画は SVG
- スタイルは Tailwind CSS

## 使い方

```bash
npm install
npm run dev
```

## 実装済み機能（MVP）

- 正しい寸法のハーフコート SVG 背景（3P ライン、フリースローサークル、ペイントエリア、リストリクテッドエリアなど）
- オフェンス／ディフェンス選手の配置（番号付き・色分け可）
- ボールの配置と保持者の設定
- 選手・ボールのドラッグ移動
- 矢印描画（実線＝移動、点線＝パス）。選手をクリックすると矢印が自動でスナップし、
  ドラッグで選手を動かすと矢印もついてくる
- 全消去 / Undo / Redo

ステップ機能（複数ステップの記録・再生アニメーション）、フリーハンドペン、テキストラベル、
JSON 保存・読み込み、PNG エクスポートは次の開発フェーズで実装予定です。
